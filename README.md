# 🚀 Customer Churn Prediction Dashboard

## 📌 Project Overview
A Machine Learning web application that predicts whether a telecom customer is likely to leave (churn) based on their usage patterns. Built to help companies reduce revenue loss by identifying at-risk customers early.

## 🎯 Business Value
- Detects high-risk customers before they leave.
- Provides a retention recommendation (e.g., send a 20% discount).
- Potential annual savings: $8,400+ for a small telecom company.

## 🛠️ Tech Stack
- Python
- Pandas & NumPy
- Scikit-learn (Random Forest)
- Streamlit (Web App)
- Joblib (Model Serialization)
